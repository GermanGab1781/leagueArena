# Icons and Such

## Folder Layout In Use
- `public/icons/map`: map nodes, HUD, upgrade, rest, shop, and event icons.
- `public/icons/relics`: relic icons.
- `public/icons/menu`: menu and social icons.
- `public/icons/settings`: settings icons.
- `public/icons/Buff_*.webp` and `public/icons/Debuff_*.webp` remain at root for combat status icons.
